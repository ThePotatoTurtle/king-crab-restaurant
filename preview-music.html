🦀 Soundtrack auditions

Three original loops, written in code — no audio files, nothing to license. Click one to hear it. The slider is set to the level it would sit at in-game.

Volume 18% — in-game background level

These are synthesised live in the browser from note data, the same way every graphic in the game is drawn from code. That keeps the whole thing one self-contained index.html with no binary assets and no attribution requirements. If you'd rather have real recorded music, say so — that needs a downloaded file plus a credit line in the README, and I'd want your go-ahead first.
